
# 💳 Credit Card Fraud Detection

This project focuses on building a machine learning model to detect *fraudulent credit card transactions* using real-world transaction data.

# ✅ Project Overview

The goal is to classify transactions as *fraudulent or legitimate* using various machine learning algorithms. This helps in minimizing financial losses and improving transaction security.

# 📊 Dataset

- Contains anonymized credit card transactions.
- Features include time, amount, and PCA-transformed variables.
- Highly imbalanced dataset: very few fraud cases.

# 🧠 Algorithms Used

- Logistic Regression  
- Decision Tree  
- Random Forest

# 🧪 Workflow

1. Data Preprocessing
2. Handling Imbalanced Data (e.g., SMOTE or undersampling)
3. Model Training & Testing
4. Evaluation using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix


# 📈 Results

- Successfully classified fraudulent transactions with good performance.
- Random Forest achieved the highest accuracy and recall.


# 🛠️ Tools & Libraries

- Python, Pandas, NumPy
- Scikit-learn, Matplotlib, Seaborn
